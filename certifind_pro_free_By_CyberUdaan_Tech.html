Zero-Configuration Architecture • 100% Free to Run

Thorough API & Dependency Audit

This application is engineered to work out-of-the-box with zero paid APIs and zero mandatory API keys. Below is the complete breakdown of how each module operates:

1. Core Catalog (32 Courses), 5 Pathways & 10 Offers No API Needed (Offline-Ready)

Stored natively in client-side JavaScript and persisted via browser localStorage. Requires no database server or external API.

2. Auto-Online Link Availability Validator No API Key Needed (Browser Fetch)

Uses the browser's built-in fetch(url, { mode: 'no-cors' }) and navigator.onLine events to verify live DNS/HTTPS reachability of all 42 official URLs directly from the client.

3. Live Web Discovery (DEV.to & GitHub Public APIs) No API Key Needed (Public CORS)

Fetches live certification guides and open-source free course repositories using the unauthenticated public REST endpoints https://dev.to/api/articles and https://api.github.com/search/repositories.
